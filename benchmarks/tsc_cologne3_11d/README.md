# Cologne3 Traffic Signal Control 11D

## Background

This benchmark selects fixed green-phase durations for three coupled Cologne
intersections to reduce network-wide traffic delay.

## Decision vector and bounds

The 11D vector contains green-phase durations in seconds. Exact names,
movements, defaults, and bounds are listed in `definition.json`. Evaluation is
restricted to the archived 5,000-point pool.

## Scalar minimization objective

The objective is total vehicle waiting time from the corresponding SUMO run;
minimize it because lower is better.

## Evaluation and required data

The evaluator looks up `x` in `data/pool_objectives.jsonl`. It does not rerun
SUMO.

## Data/framework source

The table was generated by this project using SUMO and the RESCO Cologne3
scenario. Citations and scenario terms are in third-party notices.

## Python example

```python
import json
from pathlib import Path
from benchmarks.tsc_cologne3_11d.benchmark import evaluate
x = json.loads(Path("tsc_cologne3_11d/examples/candidate_0.json").read_text())
print(evaluate(x))
```

## CLI example

```bash
python evaluate.py tsc_cologne3_11d --x-file benchmarks/tsc_cologne3_11d/examples/candidate_0.json
```

## Limitations

Bounds describe the sampled region but do not make this a continuous
benchmark. Off-pool vectors are rejected.
