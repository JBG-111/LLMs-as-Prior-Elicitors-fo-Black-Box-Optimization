# User-supplied COF benchmark arrays

The COF arrays are not distributed with this public release because the
upstream repository did not declare an explicit redistribution license when
this package was assembled.

To enable the `cof14d` evaluator, obtain the data from an authorized source
and place these two files in this directory:

- `candidates.npy` -- expected SHA-256:
  `1bd7fd8658eb61beac34577a663c937182e861566e8f3c4bd18cf07d9c128fb4`
- `objective_values.npy` -- expected SHA-256:
  `bbf58432765d99096bcfddad0fd439ab493a07917933bb2cb496557ac6242437`

The scientific source and provenance are documented in
`../../../THIRD_PARTY_NOTICES.md`. Users are responsible for ensuring that
their acquisition and use of the arrays comply with the source terms.
