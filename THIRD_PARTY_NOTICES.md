## COF 14D

The 14 descriptors and high-fidelity Xe/Kr GCMC selectivities derive from the
repository accompanying N. Gantzler et al., *Multi-fidelity Bayesian
Optimization of Covalent Organic Frameworks for Xenon/Krypton Separations*:

- https://github.com/SimonEnsemble/multi-fidelity-BO-of-COFs-for-Xe-Kr-seps

That upstream repository did not display an explicit root license when this
suite was assembled. Public accessibility is not itself a redistribution
license. Therefore, the COF candidate and objective arrays are not included in
this public release. Users must obtain them from an authorized source and
comply with its terms.

## Net3 Profile F

`Net3.inp` is EPANET Example Network 3, distributed with EPA EPANET and WNTR.
The simulation uses WNTR 1.5.0 as a dependency:

- https://github.com/USEPA/WNTR
- https://usepa.github.io/WNTR/
- https://www.epa.gov/water-research/epanet

The suite does not relicense WNTR or EPANET.

## Caltech and JPL EV charging

The environment and packaged session models derive from SustainGym and
ACNPortal. Vehicle behavior is based on ACN-Data, and the marginal operating
emissions-rate files are the SustainGym `SGIP_CAISO_SCE` inputs obtained from
the SGIP/WattTime signal source.

- SustainGym: https://github.com/chrisyeh96/sustaingym
- ACNPortal: https://github.com/zach401/acnportal
- ACN-Data: https://ev.caltech.edu/dataset
- MOER description: https://watttime.org/data-science/data-signals/marginal-co2/

The GMM pickle files must be loaded only from trusted sources. Their recorded
SHA-256 hashes are checked before the simulator is created.

## Cologne3 and Cologne8

The objective tables were generated by this project with SUMO and the RESCO
traffic-signal benchmark. The lookup suite contains neither the RESCO code nor
the Cologne network/route files.

- RESCO: https://github.com/Pi-Star-Lab/RESCO (GPL-3.0 code)
- SUMO: https://eclipse.dev/sumo/
- Cologne scenario files in RESCO carry CC BY-NC-SA 3.0 notices.

The packaged JSONL tables contain only sampled timing vectors, scalar waiting
times, and minimal evaluation metadata produced by this project.
